# DeFi Course — Vega Institute

Репозиторий с учебными материалами по курсу **«DeFi»** от **Vega Institute**.

## 📚 О курсе

Здесь собраны конспекты, домашние задания, практические работы и полезные материалы, которые я изучаю в рамках курса по децентрализованным финансам (DeFi).

**Что рассматривается в курсе:**
- Основы блокчейна и смарт-контрактов
- Децентрализованные биржи (DEX)
- Лендинговые протоколы и займы
- Стейблкоины и их виды
- Yield farming и ликвидный майнинг
- Управление рисками в DeFi
- Аудит смарт-контрактов

> Структура будет обновляться по мере прохождения курса.

## 🛠 Используемые технологии и инструменты

- **Solidity** — язык смарт-контрактов
- **Hardhat / Foundry** — среды разработки
- **MetaMask** — кошелёк
- **Remix IDE** — онлайн-среда для Solidity
- **Etherscan** — обозреватель блокчейна

## 🎯 Цель репозитория

- Систематизировать знания, полученные на курсе
- Хранить выполненные задания и проекты в одном месте
- Отслеживать прогресс обучения
- Делиться материалами с другими студентами
